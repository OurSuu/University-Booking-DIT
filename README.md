# 🎓 ระบบปฏิทินประกาศงานและลงทะเบียนเก็บชั่วโมงทุน (Scholarship Activity Calendar)

ระบบเว็บแอปพลิเคชันสำหรับอาจารย์ในการประกาศรับสมัครนักศึกษาช่วยงานเก็บชั่วโมงทุน และสำหรับนักศึกษาในการตรวจสอบตารางงาน ชั่วโมงทุนที่ได้รับ จำนวนที่นั่งว่าง และกดลงทะเบียน/ถอนชื่อได้โดยไม่ต้องมีระบบ Login

---

## ✨ คุณสมบัติหลัก (Features)

### 👨‍🏫 ฝั่งอาจารย์ (ผู้สร้างงาน)
- **ระบบยืนยันสิทธิ์ด้วยรหัส PIN สั้นๆ** (ค่าเริ่มต้น `1234` ตั้งค่าได้ใน `.env`) ป้องกันนักศึกษากดสร้างหรือลบงานโดยไม่ตั้งใจ
- **สร้าง/แก้ไข/ลบประกาศงานบนปฏิทิน**: กำหนดชื่องาน รายละเอียด ชื่ออาจารย์ผู้รับผิดชอบ และสถานที่นัดหมาย
- **ตั้งค่ากะ/ช่วงเวลาทำงานได้อิสระ**:
  - 1 งานสามารถแบ่งได้หลายกะ/ช่วงเวลา (เช่น กะเช้า `09:00 - 12:00`, กะบ่าย `13:00 - 16:00` หรือกำหนดเวลาเอง)
  - กำหนด **จำนวนชั่วโมงทุน (ชม.)** และ **จำกัดจำนวนรับนักศึกษา (คน)** แยกตามแต่ละกะได้
- **ตั้งค่าเงื่อนไขทุน กยศ.**: เลือกได้ว่างานนี้ **รับทุกทุน (รวม กยศ.)** หรือ **ไม่รับทุน กยศ.** (ระบบจะบล็อกอัตโนมัติหากนักศึกษาเลือกทุน กยศ. ในงานที่ไม่รับ)
- **ดูและคัดลอกรายชื่อผู้เข้าร่วม**: ตรวจสอบรายชื่อนักศึกษาที่ลงทะเบียนในแต่ละกะ พร้อมปุ่มคัดลอกรายชื่อทั้งหมดไปใช้งานต่อได้ทันที

### 🎓 ฝั่งนักศึกษา (ผู้ลงทะเบียน)
- **ไม่ต้องสมัครสมาชิกหรือ Login**: กรอกเพียง **รหัสนักศึกษา, ชื่อ-นามสกุล, คณะ และชื่อทุน**
- **ปฏิทินดูง่าย**: เห็นงานที่เปิดรับในแต่ละวัน จำนวนชั่วโมงทุน จำนวนที่ว่าง และเงื่อนไขทุน กยศ.
- **ระบบค้นหางานของตัวเอง**: พิมพ์รหัสนักศึกษาหรือชื่อตัวเองในช่องค้นหาเพื่อดูรายการงานทั้งหมดที่ตัวเองลงทะเบียนไว้
- **กฎการยกเลิก/ถอนชื่ออัตโนมัติ**:
  1. ยกเลิกได้ล่วงหน้า **อย่างน้อย 2 วันก่อนวันงานจริง**
  2. หากเหลือน้อยกว่า 2 วัน (เช่น เหลือ 1 วัน หรือวันงาน) จะไม่สามารถยกเลิกได้ **ยกเว้นเพิ่งมากรอกชื่อลงทะเบียนในวันนั้น แล้วเปลี่ยนใจ สามารถถอนชื่อได้ภายในวันนั้นเลย**

---

## 🗄️ การแยกฐานข้อมูล (Database)
- ระบบนี้ใช้ตารางชุดใหม่ทั้งหมด (`scholarship_jobs`, `scholarship_shifts`, `scholarship_registrations`) แยกจากระบบเดิมอย่างสมบูรณ์
- **โหมด PostgreSQL (Production / Cloud)**: ตั้งค่า `DATABASE_URL` ในไฟล์ `frontend/.env.local` (เช่นจาก Neon, Supabase หรือ PostgreSQL ตัวใหม่) ระบบจะสร้างตารางให้อัตโนมัติ
- **โหมดทดสอบในเครื่อง (Local Fallback)**: หากยังไม่ได้ตั้งค่า `DATABASE_URL` ระบบจะบันทึกข้อมูลลงไฟล์ `frontend/.data/scholarship-db.json` อัตโนมัติ ทำให้รันทดสอบได้ทันที

## 🚀 วิธีรันโปรเจกต์ในเครื่อง (How to Run)

